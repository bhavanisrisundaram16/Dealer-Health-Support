# 🚗 Automotive Dealer Health & Triage Dashboard

An interactive R Shiny prototype built to triage regional automotive dealer networks, diagnose hidden operational risks (inventory ageing, DSO, CSAT), and generate AI-powered executive recommendations.

### 🚀 **[Click Here to Open the Live App Instantly](https://bhavanisrisundaram16.github.io/Dealer-Health-Support/)**

---

## 📂 Project Structure
* `app.R` — Main R Shiny application source code.
* `Dealer Sales Data.xlsx` — Underlying Indian regional dealership dataset.
* `docs/` — Compiled WebAssembly assets powering the GitHub Pages deployment.

## 🛠️ Tech Stack
* **R Shiny & bslib** (Modern UI & Layout)
* **Shinylive & WebAssembly** (Client-side browser execution)
* **OpenAI API (BYOK)** (Secure, on-demand AI executive insights)
